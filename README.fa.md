## ✨ چرا پیام‌بان؟

همهٔ اپ‌های پیامک همین دسترسی‌ها را می‌خواهند، ولی بیشترشان پیام‌هایت را به سرور می‌فرستند. اپ‌های تبلیغاتی «شناسهٔ تماس» بدترند: کل صندوق ورودی را برای ساختن دیتابیس خودشان آپلود می‌کنند.

**پیام‌بان دقیقاً برعکس عمل می‌کند.** تشخیص اسپم، شناسایی فرستنده، خوشه‌بندی کمپین‌ها و یادگیری از اصلاح‌های تو، همه **روی خود گوشی** و با کاتلین ساده انجام می‌شود — **بدون هیچ درخواست شبکه‌ای**. نه تبلیغ، نه ردیاب، نه تحلیل‌گر، نه اکانت ابری.

| | |
|---|---|
| 🔒 **هیچ‌چیز از گوشی بیرون نمی‌رود** | بدون سرور، بدون تلومتری، بدون SDK شخص ثالث. نسخهٔ `offline` حتی مجوز `INTERNET` هم نمی‌گیرد. |
| 🧠 **فیلتر قابل توضیح** | هر تصمیم با امتیاز و دلیل فارسی می‌آید (`لینک · ایجاد عجله · لغو اشتراک انبوه`) — نه یک جعبهٔ سیاه. |
| 🧩 **یادگیری روی دستگاه** | با اصلاح یک پیام، قاعده‌های خودت برای همان فرستنده یاد گرفته می‌شود. |
| 🚫 **کمپین، نه فقط پیام** | SimHash ۶۴ بیتی پیام‌های انبوهِ تقریباً یکسان را خوشه می‌کند؛ یک تصمیم برای کل کمپین. |
| 🎨 **متریال ۳ و راست‌چین‌اول** | از پایه برای فارسی: فونت وزیرمتن، مدیریت درست جهت متن، تم روشن/تیره، مقیاس فونت قابل تنظیم. |
| 🗂️ **سطل زبالهٔ واقعی** | پیام حذف‌شده به سطل زباله می‌رود و قابل بازگردانی است، نه اینکه برای همیشه محو شود. |

## 🚀 امکانات

### صندوق ورودی و گفتگوها
- فهرست گفتگوها با پوشه‌های **سنجاق‌شده**، **خوانده‌نشده**، **بایگانی** و **سطل زباله**
- چیپ دسته‌ها — مخاطبین · بانکی · رمز پویا · اطلاع‌رسانی · تبلیغاتی · اسپم
- جستجوی متنی روی کل دیتابیس provider، با دیبانس و نتایج زنده
- لمس طولانی برای انتخاب، سپس **انتخاب بازه‌ای**؛ کپی، اشتراک، گزارش اسپم و حذف از نوار اکشن جمع‌وجور
- سویپ، رنگ و آواتار هر فرستنده، جداکنندهٔ روز، و ارسال زمان‌بندی‌شده

### فیلتر و هوش
- موتور سیگنال وزن‌دار و قابل توضیح: لینک، عجله، وعدهٔ مالی، هدر لغو اشتراک، متن دستکاری‌شده، جعل برند، دامنهٔ پرخطر، لینک IP، پونی‌کد…
- نرمال‌ساز فارسی‌آگاه — عربی→فارسی، کشیده، نیم‌فاصله، ارقام عربی/فارسی — همان ترفندهایی که فرستنده‌های انبوه برای دور زدن فیلتر استفاده می‌کنند
- پروفایل فرستنده و وزن‌های یادگرفته‌شده، اصلاح‌های تو را نگه می‌دارند
- کاتالوگ برندها: بانک‌های ایرانی، اپراتورها، فروشگاه‌ها و پست (با تشخیص تایپواسکات)
- هوش لینک و شماره تلفن، کاملاً آفلاین

### حریم خصوصی و کنترل
- سیاست هر فرستنده: *همیشه تحلیل کن*، *هرگز تحلیل نکن*، *مسدود کن*، *مورد اعتماد*
- قانون‌ساز (فرستنده / کلیدواژه / الگو) با پیش‌نمایش زندهٔ «چند پیام موجود تطبیق دارد»
- ذخیرهٔ رمزنگاری‌شدهٔ مقادیر حساس (AES/GCM روی Android Keystore)
- پشتیبان‌گیری و بازگردانی تنظیمات — بدون اکانت، بدون ورود، بدون همگام‌سازی

## 📦 نصب

### راه ۱ — دانلود APK
آخرین APK امضاشده را از صفحهٔ [**Releases**](../../releases/latest) بگیر.

| نسخه | مجوز اینترنت | چه وقت |
|---|---|---|
| `offline` | ❌ ندارد | حداکثر حریم خصوصی — بدون پیش‌نمایش لینک و بدون هیچ مسیر کد شبکه‌ای. |
| `full` | ✅ `INTERNET` | پیش‌نمایش امن لینک‌های داخل پیام. |

### راه ۲ — بیلد از سورس
```bash
git clone https://github.com/turboboy2006/sms-guard.git
cd sms-guard
./gradlew assembleOfflineRelease   # یا: assembleFullRelease
```
نیازمند **JDK 17** و Android SDK (compileSdk 34). CI هر پوش را با هر دو flavor می‌سازد — [`.github/workflows/build.yml`](.github/workflows/build.yml).

### پیش‌نیاز
اندروید ۸.۰ (API 26) یا بالاتر.

## 🛡️ Play Protect

اگر APK را خارج از Google Play نصب کنی، اندروید ممکن است هشدار «Play Protect» نشان دهد. این یک هیوریستیک است، نه حکم — اپ‌های پیامکی نصب‌شده خارج از فروشگاه تقریباً همیشه این هشدار را می‌گیرند.

راه‌ها:
1. **نصب با کابل:** `adb install -r payamban.apk` — دیالوگ Play Protect مربوط به رابط نصب‌کننده است و این مسیر معمولاً بدون آن نصب می‌کند.
2. **خاموش کردن موقت اسکن:** Play Store → پروفایل → Play Protect → چرخ‌دنده → *Scan apps with Play Protect* را موقتاً خاموش کن.
3. **اعتراض به گوگل:** [فرم Play Protect Appeals](https://support.google.com/googleplay/android-developer/contact/protectappeals) — با IP غیرایرانی باز می‌شود و یک لینک دانلود مستقیم APK می‌خواهد.
4. **راه قطعی:** انتشار در Google Play با فرم استثنای مجوز SMS.

> در این اپ گزینهٔ **«هشدار Play Protect»** داخل کارت راهنمای نقش پیش‌فرض، همین فرم را باز می‌کند.

## 🏗️ ساختار پروژه

```
app/src/main/java/ir/inod/smsguard/
├── MainActivity.kt              # صندوق، تب‌ها، فیلتر، اکشن‌های گروهی
├── ConversationActivity.kt      # نمایش گفتگو، انتخاب، ترکیب‌کننده
├── FolderActivity.kt            # پوشه‌های بایگانی و سطل زباله
├── TrashedMessagesActivity.kt   # سطل زبالهٔ پیام‌ها (قابل بازگردانی)
├── Classifier.kt                # موتور سیگنال وزن‌دار (قابل توضیح)
├── Normalizer.kt                # نرمال‌سازی فارسی/عربی
├── LearningStore.kt             # پروفایل فرستنده و وزن‌های یادگرفته‌شده
├── Campaign.kt                  # خوشه‌بندی کمپین با SimHash
├── UrlIntel.kt / PhoneIntel.kt  # هوش آفلاین لینک و شماره
├── SmsRepository.kt             # دسترسی به provider، رشته‌ای و کش‌شده
├── Store.kt                     # تنظیمات، دسته‌ها، سیاست فرستنده
├── RulesActivity.kt             # قانون‌ساز + پیش‌نمایش تطبیق
├── ManagerActivity.kt           # مدیریت فرستنده‌ها
└── SettingsActivity.kt          # ظاهر، اعلان، پشتیبان‌گیری
```

یادداشت‌های معماری و نُه دامی که در مسیر ساخت به آن‌ها خوردیم در [`HANDOFF.md`](HANDOFF.md) و [`UI-FIXES-PLAN.md`](UI-FIXES-PLAN.md) مستند شده است.

## 🔐 حریم خصوصی

- **در نسخهٔ `offline` مجوز `INTERNET` وجود ندارد** — سیستم‌عامل این را تضمین می‌کند، نه یک وعده.
- **بدون تحلیل‌گر، بدون گزارش خطا، بدون تبلیغ، بدون SDK شخص ثالث.**
- **بدون اکانت.** چیزی برای ورود و چیزی برای همگام‌سازی نیست.
- متن پیام فقط برای دسته‌بندی خوانده می‌شود و در حافظهٔ خصوصی اپ می‌ماند.

## 🤝 مشارکت

ایشو و پول‌ریکوئست پذیرفته می‌شود. شروع‌های خوب:

1. یک ایشو با **الگوی پیامی** که فکر می‌کنی اشتباه دسته‌بندی شده باز کن — شماره‌ها و کدها را ماسک کن.
2. اپ را اجرا کن، چند پیام را اصلاح کن و قانون‌های یادگرفته را از *تنظیمات → پشتیبان* بیرون بکش.
3. یک PR برای افزودن سیگنال، برند یا ترجمه بفرست.

لطفاً موتور را **آفلاین و قابل توضیح** نگه دار: هر سیگنال جدید باید یک دلیل قابل نمایش اضافه کند.
